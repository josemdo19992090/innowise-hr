# HR Scout — оценка кандидатов с ИИ

MVP для HR небольших компаний: загрузка резюме (PDF) → оценка ИИ относительно вакансии → рейтинг → чек-лист собеседования → статистика.

Stack: Next.js (App Router, JS), Tailwind CSS, Gemini API (REST), `unpdf` для извлечения текста. Хранилище: `data/db.json` локально, [Vercel KV](https://vercel.com/docs/storage/vercel-kv) автоматически при деплое (см. `lib/db.js`).

## Запуск локально

```bash
npm install
cp .env.local.example .env.local   # добавить GEMINI_API_KEY
npm run dev
```

Открыть http://localhost:3000.

`.env.local`:

```
GEMINI_API_KEY=...
GEMINI_MODEL=gemini-3.8-flash   # можно сменить без правок кода; см. доступные модели на aistudio.google.com/apikey
```

Бесплатный тариф Gemini ограничен ~5 запросами в минуту — загружать резюме партиями по 4–5.

## Деплой на Vercel (публичная ссылка)

1. Запушить репозиторий на GitHub, импортировать в [vercel.com](https://vercel.com) → New Project.
2. В проекте: **Storage → Create Database → KV** (создаёт бесплатное хранилище и сам подставляет переменные `KV_*`).
3. **Settings → Environment Variables** — добавить `GEMINI_API_KEY` и `GEMINI_MODEL`.
4. Deploy. `lib/db.js` сам переключается на KV, когда видит `KV_REST_API_URL`.

## Демо-сценарий

1. `/` — вставить текст из `samples/vacancy.txt`, сохранить.
2. `/candidates` — загрузить все PDF из `samples/` (или реальные резюме). Файлы обрабатываются параллельно (по 3), рейтинг обновляется по мере готовности.
3. Открыть кандидата → отредактировать чек-лист, выставить оценки 1–5, сохранить собеседование.
4. `/stats` — средние баллы и самые слабые компетенции по всем собеседованиям.

Демо-резюме можно пересоздать: `node scripts/make-samples.mjs` (использует Arial из Windows; путь меняется через `CV_FONT`).

## Решения

- **Один вызов Gemini на кандидата**: оценка + чек-лист в одном JSON (экономия квоты free tier). `responseMimeType: application/json` + очистка ``` и try/catch; ошибки показываются по каждому файлу, страница не падает.
- **Поддержка, а не отказ**: промпт запрещает вердикт «подходит/не подходит» и учёт защищённых характеристик — только балл и доказательства.
- **JSON-файл вместо БД**: записи сериализуются через promise-очередь, чтобы параллельные загрузки не перезаписывали друг друга.
- **Ограничения MVP**: только PDF с текстовым слоем (сканы без OCR дают понятную ошибку), одна активная вакансия, без авторизации, сохранённые собеседования не редактируются.
